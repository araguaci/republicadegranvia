📸 SVG → PNG Converter

Converta as imagens de sharecard de SVG para PNG com um clique

Como Usar

  1. Clique em "Download PNG" para cada imagem
  2. As imagens serão baixadas individualmente como PNG
  3. Mova todos os og-*.png para a pasta /images do projeto
  4. Faça commit e push: git add images/og-*.png && git commit -m "Add OG sharecard images" && git push
  5. Pronto! As redes sociais agora mostrarão as imagens ao compartilhar
